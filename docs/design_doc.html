凡人
01

總覽

一句話：玩家扮演韓立（或自創修士），從青牛鎮的凡人少年開始，在一張忠於原著的開放地圖上拜師、修煉、突破、結仇、奪寶，走完人界六卷的歷程。遊戲本體是一個 Skyrim SE 的全面轉換模組（與《Enderal》相同的發行模式），玩家需擁有 Skyrim SE。

忠實還原

地圖、門派、角色、功法、境界全部以 data/*.json 為單一資料來源，每一條都標記 verified，方便對照原文逐條校訂。劇情按原著六卷順序推進，關鍵事件（墨大夫奪舍、血色試煉、正魔大戰、慕蘭大戰、虛天殿、昆吾山、飛升）皆為主線任務。

Skyrim 相容

不重寫戰鬥。保留 Skyrim 的 Actor Value、技能、Keyword、裝備欄位、動畫行為圖與 Perk 架構，只在其上「換皮＋加層」：法術即 Skyrim 法術、功法即 Perk 樹、法寶即附魔武器＋腳本。MCO、Precision、TK Dodge、Nemesis 等戰鬥模組原生可用。

方便擴充

主檔 ChineseRim.esm 提供 Faction、Keyword、Perk 樹與 Papyrus API；各卷地圖為獨立 .esp。第三方只要丟一個 JSON 到 SKSE/Plugins/ChineseRim/ 就能新增功法、丹藥、門派；或用 SPID 把功法分派給任何 NPC。

核心玩法迴圈

探索

開放地圖：天南諸國、坊市、秘境（血色禁地、虛天殿、昆吾山）。以 Skyrim 的 Location/Encounter Zone 控制難度。

修煉

打坐吸收靈氣（時間推進）、服丹、悟功法；修煉進度 = 經驗值。靈根決定速度。

突破

境界瓶頸鎖住升級：練氣圓滿需築基丹，築基後期需結丹靈藥。突破是事件（閉關、天劫式考驗），可失敗。

門派・戰鬥・煉製

門派聲望 = Faction Rank；煉丹 = Alchemy、煉器 = Smithing+Enchanting、布陣 = 放置物；法寶隨境界祭煉成長。

02

世界地圖

人界四大區塊各為一個 Skyrim Worldspace。示意圖為本專案自繪的相對位置圖（非原著官方地圖）：天南在南、慕蘭草原居中、大晉在北、無邊海與亂星海在東。點選區域可查看其中的城鎮、門派與秘境，以及對應的 Worldspace 與插件。

靈界（DLC）

地圖建置策略。 天南主世界以 Creation Kit 匯入高度圖（建議尺寸 128×128 Cell，與原版天際相當）；慕蘭草原共用天南插件但獨立 Worldspace；亂星海以海面為主，島嶼為 Location，配合船隻快速旅行；大晉初版只建州府、落雲宗與昆吾山等劇情節點，其餘以「傳送陣＋地圖標記」呈現，留給後續擴充填滿。
03

境界體系

境界是遊戲的骨幹進度條。Skyrim 的玩家等級（1–100）對應人界五境，每一境再切初/中/後期；升級到境界上限時會被「瓶頸」鎖住，必須完成突破事件（丹藥＋閉關＋考驗）才能繼續。靈界境界留給 DLC，等級 100 以上。

靈根（角色創建）

靈根取代 Skyrim 的種族選擇：決定五行親和（對應法術傷害加成）與修煉速度倍率（經驗值倍率）。「原作模式」鎖定韓立的四靈根＋掌天瓶；「自由模式」可自選。

04

門派與勢力

每個門派是一個 Skyrim Faction；聲望用 Faction Rank（-4 死敵 ～ 4 核心弟子）表示，門派任務、店鋪折扣、洞府使用權、功法解鎖都以 Rank 為條件。正魔陣營以父 Faction 統一敵對關係，子宗自動繼承。

05

角色

具名角色各有一個 ActorBase，境界隨劇情推進（用 Leveled Actor 或腳本 SetLevel）。同伴（銀月、厲飛雨、南宮婉）走 Skyrim 追隨者框架，因此 NFF、AFT 等追隨者模組可直接管理他們。

06

功法・法術・法寶

三層設計：功法是 Perk 樹（長期成長）、法術是 Skyrim 法術（即時施放）、法寶是可祭煉成長的物品。每個條目都寫明對應的 Skyrim 基底，方便在 Creation Kit 裡照表建立。

07

戰鬥系統

原則：不改 Skyrim 的骨架，只換血肉。所有玩家與 NPC 仍用原版的三大屬性、18 項技能、裝備欄位與動畫行為圖，因此任何為 Skyrim 寫的戰鬥模組（動作、閃避、鎖定、命中判定、AI）不需修改即可套用。修仙元素透過「對照層」實作。

五行相生相剋

傷害倍率：剋制 ×1.5、被剋 ×0.75、相生對友方加持 +15%。變異屬性（雷/冰/風）各自對應一個五行父屬性（雷→木、冰→水、風→木）以繼承剋制關係。

戰鬥節奏

  • 凡人階段（七玄門）：純近戰 + 格擋，Skyrim 原味；教學關。
  • 練氣：法術 + 法器（飛劍作為投射武器）；靈石有限，逼迫玩家在坊市與採集間取捨。
  • 築基：神識開啟（敵人境界可視）、御器飛行（滑翔級）、符籙一次性法術。
  • 結丹：金丹威壓讓低境界敵人恐懼；法寶祭煉；劍陣。
  • 元嬰：元嬰出竅（高風險高輸出）、傀儡軍、奪舍（NPC 專屬）。
  • Boss 設計：忠實原作的「不能正面打」戰鬥（墨大夫：毒＋陷阱；曲魂：破解五行輪），以任務階段控制。

飛行

Creation Engine 沒有原生玩家飛行。分兩級：築基使用滑翔（Paraglider 類框架，社群成熟）；結丹以上整合開源飛行框架（以 SKSE 插件實作，參考 Flying Mod / Skyrim Flying 的 havok 處理）。飛行時禁用 MCO 近戰動畫集，切換至「御劍」動畫圖（DAR/OAR 條件）。元磁神光可使目標「禁飛」。

相容性守則

  • 不刪除、不改名原版 Actor Value、Keyword、Skill、裝備 Slot、Race 骨架（靈根為 Race 的子分類，骨架用 Nord 標準骨架）。
  • 不覆寫原版行為圖 0_master.hkx；新增動畫透過 Nemesis/Pandora 補丁。
  • 法術傷害走原版 Magic Effect，讓「法術縮放」「傷害倍率」類模組照常作用。
  • 所有新記錄以 CR_ 前綴，避免 EditorID 衝突。
  • 境界數值以 Skyrim 等級 1–100 尺度壓縮（見境界表），確保等級縮放類模組不會炸掉數值。

資料驅動：JSON 直接掛載

遊戲啟動時 CR_Registry 掃描 Data/SKSE/Plugins/ChineseRim/techniques/、sects/、pills/ 下所有 JSON 並合併。第三方新增一部功法只需一個檔案，並在自己的 .esp 內建立對應 Perk（EditorID 對上即可）。

// Data/SKSE/Plugins/ChineseRim/techniques/MyMod_XuanYinJue.json
{
  "gongfa": [{
    "id": "mymod_xuanyin_jue",
    "name": "玄陰訣",
    "element": "水",
    "minRealm": "foundation",
    "perkTree": "MyMod_Tree_XuanYin",     // 在 MyMod.esp 建立的 Perk 樹 EditorID
    "perks": ["MyMod_Perk_XuanYin01", "MyMod_Perk_XuanYin02"],
    "learnItem": "MyMod_Book_XuanYin"      // 功法典籍（Book）
  }]
}

主線任務（人界六卷）

主線依原著順序切成六卷，每卷一個 Quest 章節（CR_MQ##）。玩家境界與等級區間配合境界表，讓「突破」成為卷與卷之間的節點。支線（門派任務、坊市、秘境）不在此列。
